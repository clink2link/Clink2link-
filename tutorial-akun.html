Settings Account

Guide mengatur profile, keamanan, and payment account Click2Pay.

1. Buka Menu Setting

Sign In ke Dashboard lalu pilih menu Setting for mengatur account you.

2. Ubah Data Profile

You dapat memperbarui informasi account seperti username and data profile that tersedia.

3. Ganti Password

Gunakan password that kuat and lakukan perubahan secara berkala for menjaga keamanan account.

4. Atur Payments Setting

Tambahkan atau ubah bank account bank maupun e-wallet that digunakan for withdraw.

5. Periksa Informasi Account

Pastikan seluruh data account selalu benar agar tidak mengalami masalah saat menggunakan fitur Click2Pay.

Tips Keamanan Account

Gunakan password unik, jangan membagikan kode keamanan kepada orang lain, and selalu pastikan login dilakukan melalui website resmi Click2Pay.

Lindungi Account You

Jika menemukan activity mencurigakan, segera ubah password and hubungi support Click2Pay.
